# QR File Transfer: start here

**Continuing this tool? Read [the detailed handover](HANDOVER.md).** For pictures and operation, use the [manual](USER-MANUAL.md) and [offline demo](../demo.html).

Optical file transfer using QR frames, recovery and exact-byte reconstruction. The demo illustrates chunk ordering; it is not the production MQF1 transport or a speed benchmark.

**Start with:** Prepare a small first transfer. Open the sender page on the sending computer. Use the included harmless hello.txt example before trying a large archive.

**Source:** this is a private source checkpoint, not a live-system mirror. Check [the source manifest](../SOURCE-MANIFEST.json) and current working files before merging.

**Keep your work safe:** The browser candidate stores progress locally; it does not silently send files to a cloud service. A camera recording or someone else’s view of the sender screen can expose the transmitted content: encoding and recovery are not encryption. Keep source files until the received copies are verified and saved.

**Next maintainer action:** Validate real sender/receiver phones, camera permissions, loss/resume and throughput using harmless samples. Keep this project private even if all release preparation is complete; publication needs separate owner approval.
